Puerto Protocolo Estado Servicio Banner / Versión Identificada

Escaneo de puertos perimetrales no ejecutado. Se evaluarán los puertos 22, 80, 443 y 8080.

1. HTTP Strict Transport Security (HSTS)

Configurar la cabecera Strict-Transport-Security: max-age=31536000; includeSubDomains; preload en los servidores perimetrales para forzar el uso estricto de HTTPS en toda la navegación.

2. Content-Security-Policy (CSP) Restrictiva

Establecer políticas formales para la carga de scripts, fuentes y estilos a fin de mitigar vectores de inyección de código y vulnerabilidades Cross-Site Scripting (XSS).

3. Minimización de Divulgación de Banners

Deshabilitar la firma en cabeceras Server y eliminar X-Powered-By en Apache, Nginx o frameworks web para prevenir el fingerprinting de versiones específicas.

4. Restricción Perimetral de Puertos Administrativos

Garantizar que puertos como el 22 (SSH) o consolas en el puerto 8080 no estén expuestos directamente a redes públicas sin filtrado previo por VPN institucional.
